# Notice — exercise animation media

The looping exercise animations in `assets/exercises/*.gif` are the animation
GIFs from the free open-source **exercises-dataset** by hasaneyldrm
(https://github.com/hasaneyldrm/exercises-dataset, 1,324-exercise fitness
dataset, MIT license for code/data).

The animation media itself is **© Gym visual — https://gymvisual.com/**,
provided in the dataset with permission for educational / application use.
If you ship PULSE commercially, confirm the Gym visual media terms or swap in
your own licensed animations — the app falls back to its built-in animated SVG
figure automatically for any exercise without a bundled GIF.

- Dataset: https://github.com/hasaneyldrm/exercises-dataset
- Media source: https://gymvisual.com/
